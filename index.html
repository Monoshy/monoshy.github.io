发布到 GitHub

将当前计划发布到你的 GitHub Pages（monoshy.github.io）：
① 同步计划数据：更新线上 plan.json，别人打开 monoshy.github.io 即可看到你发布的最新进度（只读展示版）。
② 更新页面文件：选择本机的 index.html 上传，用于同步网页本身的功能/样式改版。

Token 创建（一次性）：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access 选 Only select repositories 并勾选你的 monoshy.github.io 仓库 → 权限里勾选 Contents: Read and write → 生成后粘贴到下方。
Token 仅保存在你本机浏览器，不会上传到任何地方；发布后可在 GitHub 上随时撤销。
